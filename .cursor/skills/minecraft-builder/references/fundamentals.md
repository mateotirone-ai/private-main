## The habits that separate boxes from builds

1. **Stop single-block walls** — mix 3–5 related materials.
2. **Stop flat walls** — inset/outset, pillars, stairs/slabs for micro-shadow.
3. **Plan footprint first** — dirt/wool template; walk it; fix proportions early.
4. **Shape before texture** — varied plan beats a detailed rectangle.
5. **Roof is mandatory** — different material, overhang, correct style.
6. **Landscape is part of the build** — paths, plants, custom trees, terrain blend.
7. **Light intentionally** — lanterns / hidden glow; no torch acne.
8. **Interior has program** — rooms with purpose; furniture improvisations.
9. **Use references** — real architecture + 3–5 photo refs before committing.
10. **Do not over-detail** — if chaotic from afar, cut slabs/stairs spam.

## Palette structure (Switchblade / BuildingGuide / Gradient blog)

| Role | Share | Job |
|---|---|---|
| Primary | ~50–60% | Dominant wall/roof field |
| Secondary / transition | ~30% | Texture contrast, same tone family |
| Accent | ~10–20% | Corners, trim, landmarks only |

Share warm/cool tone; vary texture. Build a test swatch before committing.

Example starter palettes (adapt to project sandstone/spruce/mud-brick world):

- Cozy house: oak → stripped oak → spruce → barrel → lantern
- Desert village: sandstone → cut → smooth → terracotta → mud bricks
- Stone wall: stone bricks → stone → andesite → tuff → cracked → deepslate
- Cave mouth: grass → coarse dirt → gravel → stone → tuff → deepslate
- Copper accent: bricks/mud bricks → exposed/weathered copper → spruce trapdoors

## Depth toolkit

- Inset windows 1 block; panes often beat full glass blocks for thinness.
- Outcropped / diagonal corner frames (pilasters).
- Alternate column depth every 3–4 blocks on long walls.
- Upside-down stairs as sills; slabs as base ledges.
- Roof overhang 1–2 (often 2) blocks → shadow line that “finishes” the wall.
- Log pillars every 3–5 blocks on exteriors.
- Recess doors one block; upside-down stair above door for depth.

## Interiors

- Chairs: stairs + optional side signs/arms.
- Tables: fence posts + pressure plate / carpet / slab top.
- Cabinets: barrels, chests, trapdoors.
- Libraries: bookshelves + item frames.
- Ceilings: add beams/logs/trapdoor panels — do not leave raw underside of upper floor.
- Scale: player ~2 tall; doors 2–3; ceilings 3–4; rooms ≥4×4 for furniture.

## Lighting (no torch spam)

- Lanterns on fence posts / hanging.
- Glowstone / shroomlight under carpet or behind trapdoors.
- Candles for mood clusters.
- Sea lanterns / end rods for modern or cool palettes.
- Bottom slabs / non-full tops also reduce spawns when used as floors.

## Landscaping & paths

- Never a perfect grass square under the pad.
- Paths: dirt path, coarse dirt, gravel, podzol, brown terracotta + button “pebbles”.
- Roads: stone / concrete families with edge noise.
- Terrain: no >~7 straight equal runs when shaping natural ground.
- Cut into hillsides; terrace; retaining walls at cut seams.
- Add atmosphere props along paths: benches, ponds, campsites — sparse.
- Custom trees near hero builds; messy leaf canopies, mixed leaf types, leaves off the trunk.

## Town / multi-building notes (TheGamer + TeamVisionary)

- Theme each activity building while keeping a shared town palette.
- Connect with intentional paths/roads.
- Template wool massing for scale before materials.
- Experiment window/wall variants side-by-side; pick the winner.
- Start small; detail after massing reads.
- Cohesion across nearby buildings beats one over-detailed orphan.

## Common mistakes checklist

- [ ] Single-block material
- [ ] Flat walls
- [ ] Pure rectangle footprint
- [ ] No / flat wrong-style roof
- [ ] Floating unsupported overhangs
- [ ] Dirt showing under foundation
- [ ] Torch spam
- [ ] Empty interiors
- [ ] Over-detail noise
- [ ] Build ignored by terrain
- [ ] Perfect symmetry with no intentional asymmetry
- [ ] Walls 1-block thick on “solid” architecture (prefer 2–3 where readable)
